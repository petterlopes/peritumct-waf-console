    Privacy policy
    
        
    This policy covers the CrowdSec WAF operator console (/waf). It is an administration tool on loopback and the admin overlay. It is not a public website and is not the privacy notice of periciacomputacional.com, neurofocus.com.br, or other origin sites.
    
        
    Controller
    
        
    Controller: Petter Anderson Lopes, operating as PERITUM / Perícia Computacional. Contact and professional profile: periciacomputacional.com/sobre.
    
        
    Data processed
    
        
    The console reads CrowdSec LAPI security telemetry (source IPs, URIs, rule names, country codes and coordinates supplied by the engine, decisions, allowlists) and stores operator policy documents plus a local audit JSONL. Lawful basis: legitimate interest and, where applicable, legal obligation to protect networks (LGPD / GDPR).
    
        
    The console does not load gtag, does not call the Google Analytics Data API, does not send CrowdSec attacker IPs to Google, does not use a third-party GeoIP service, and does not process advertising identifiers.
    
        
    Browser storage
    
        
    The operator browser may keep UI locale (waf-locale-v2) and the selected domain filter (waf-domain-v1) in localStorage. Those keys never leave the workstation except as ordinary browser storage.
    
        
    Optional GA snapshot
    
        
    An optional WAF_GA_SNAPSHOT_FILE is an operator-exported aggregate of public-site GA4 sessions by hostname and country (no client_id). Analytics does not contribute until that file has at least one session count greater than zero. Dest default is inactive.
    
        
    Retention
    
        
    CrowdSec decisions follow engine TTL (console cap 168h for manual bans). Rotate audit.jsonl with the host log policy (example: 90 days). LAPI alert history follows the CrowdSec allocation, not this UI.
    
        
    Rights
    
        
    This UI is not a consumer app and does not answer data-subject requests. End-user IPs appear only as security telemetry inside CrowdSec. Access, correction and erasure follow the operator CrowdSec/LAPI retention process and the public-site notices, not a form in this console.
